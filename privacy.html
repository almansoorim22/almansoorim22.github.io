Privacy policy — Faunotion Uploader

Last updated: 24 October 2026

Faunotion Uploader is a personal tool run by the owner of the Faunotion YouTube channel on the owner's own computer. It is used only with the owner's own Google account and YouTube channels.

What it accesses

  • youtube.upload: to upload videos the owner made to the owner's own channel.
  • youtube.readonly: to confirm which channel is authorised, check for duplicate uploads, and read the processing status of the owner's own videos.

How data is stored

The OAuth token is stored only on the owner's computer. The tool has no server and does not store, sell, share or transfer any Google user data to anyone. It does not use Google user data for advertising, and it does not use it to train AI models.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Revoking access stops the tool from uploading.

Contact

Questions can be sent through the Faunotion YouTube channel.
